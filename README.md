# 🏦 02 — ZAITO  
## Modern MERN Banking Platform

A production-ready banking system implementing secure authentication, transaction flows, and group expense management.

### 🔗 Access
**Live Application:**  
👉 https://zaito-bankingapplication.onrender.com/dashboard  

**GitHub Repository:**  
👉 https://github.com/ragavan28v/Zaito-BankingApplication

### 🔐 Core Features
- JWT Authentication  
- PIN-secured fund transfers  
- Account & balance management  
- Transaction history  
- Group expense splitting (equal/custom)  
- Force settlement with secure confirmation  

### 🏗 Architecture
Frontend: `React.js`  
Backend: `Node.js` + `Express.js`  
Database: `MongoDB Atlas`  
Security: `JWT` • `Hashed Passwords` • `Protected Routes`
